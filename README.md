# On Air Classroom

A platform for online learning and teaching.

## Overview

On Air Classroom provides a virtual space for educators and students to connect and engage in interactive learning experiences. This project aims to create a user-friendly and feature-rich online classroom environment.

## Features

* **Live Video Conferencing:** Real-time interaction between teachers and students.
* **Screen Sharing:** Teachers can share their screens for presentations and demonstrations.
* **Interactive Whiteboard:** Collaborative space for drawing and note-taking.
* **File Sharing:** Easy uploading and downloading of learning materials.
* **Chat Functionality:** Real-time text-based communication.
* **Assignment Management:** Tools for creating, submitting, and grading assignments.
* **User Authentication:** Secure login and registration for students and teachers.

## Technologies Used

* **Frontend:** React, HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Real-time Communication:** WebSockets (e.g., Socket.IO)
